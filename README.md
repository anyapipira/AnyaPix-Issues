# AnyaPix — issues & feedback

This repository only collects bug reports, questions and feature requests for **AnyaPix** by Pipira.
It contains no source code, and pull requests are not accepted.

- Web editor (free): https://pix.anya.party/
- BOOTH shop: https://anyapipira.booth.pm/
- [Open an issue](../../issues/new/choose)

## 日本語

AnyaPix（Web 版エディタ、ドット絵タブレット、入力フレーム、プリセットフレーム）の不具合報告・質問・要望を受け付けるリポジトリです。ソースコードは含まれず、プルリクエストは受け付けていません。

- 「New issue」からテンプレートを選んでください
- 製品名とバージョン（Web 版は画面左上の表示、Unity 製品は 1.0.0 など）、Unity / VRChat SDK のバージョン、再現手順を書いてください

## English

This is where to report bugs, ask questions and request features for AnyaPix (web editor, Drawing Tablet, Import Egg Frame, Preset Egg Frame). It has no source code, and pull requests are not accepted.

- Choose a template under "New issue"
- Include the product and version (web editor: shown at the top left; Unity products: e.g. 1.0.0), your Unity / VRChat SDK version and the steps to reproduce
- Please do not attach purchased unitypackages, zips or world projects (that would be redistribution). Screenshots and short videos are welcome
- Issues are public: do not post personal information or credentials
